# MATV / AVEN Vectoring Engine Simulator

An interactive 3D web-based simulation of a Multi-Axis Thrust Vectoring (MATV) engine nozzle. This application provides a detailed, hands-on visualizer for advanced aerospace propulsion systems, demonstrating how hydraulic actuators and articulated nozzle petals manipulate jet exhaust to achieve extreme maneuverability.

## Features

* **Interactive 3D Visualization:** Explore a fully rendered engine model featuring a turbofan core, spherical joints, hydraulic actuators, and articulated nozzle petals.


* **Real-time Vector Control:** Command the engine's thrust direction using a dual-axis polar radar pad or precision sliders for pitch and yaw.


* **Live Engine Telemetry:** Monitor real-time dynamic readouts, including total deflection angles, axial/vertical/lateral force components, and precise extension lengths for individual actuators.


* **Performance Metrics:** Track simulated engine statistics such as core speed, estimated exhaust temperature, exhaust speed, and estimated fuel flow.


* **Customizable Mechanics:** Adjust physics and mechanical parameters, including the actuator rate limit (degrees per second) and engine speed time-constant.


* **Visual & Audio Feedback:** Features a visual exhaust particle stream and toggleable engine audio for an immersive testing cell experience.



## Controls & Interface

The simulation provides a comprehensive control panel (Test Cell #4):

* **Throttle Command:** Slider to control overall engine output (0% to 100%).


* **Target Vector Control:** Use the circular drag pad to simultaneously command pitch and yaw, or use the dedicated linear sliders.


* **Physics Settings:** Toggles for direct-nozzle drag, auto demonstration, and exhaust visual effects.


* **Camera Controls:** Free-look orbit camera with options to center the nozzle or reset the view.
